# 이어가게

폐업·이전을 앞둔 카페 사장님이 **매장 사진 한 장으로 집기의 예상 매각 금액과 근처 판매처**를 확인하는 서비스입니다.

- 배포: Streamlit Community Cloud (`main` 머지 시 자동 재배포)
- 팀: 11팀 다음장 · CUBIG 대학 연합 해커톤 2026

## 이용 흐름 (4단계)

| 단계 | 사용자 | 서비스 |
|---|---|---|
| 01 사진 | 매장 사진 업로드·촬영 (JPG·PNG·HEIC), 필요 시 90° 회전 | 긴 변 1024px로 조정 |
| 02 물품 확인 | 박스 추가·삭제, 품목명·수량·제조사·모델명·연식 수정, 개업일 입력 | Gemini가 물품·위치·제조사·모델명 추정 |
| 03 견적 | 물품별 가격·범위·합계 확인, '가격 근거 보기', CSV 내려받기 | 코드가 시세표로 가격 계산 |
| 04 판매처 | 매장 소재지 입력, 물품별 [확인하기] | Kakao Local API로 반경 10km 업체 최대 3곳 |

## 구조

```
사진 → Gemini(gemini-3.1-flash-lite, 1회 호출) → 코드 후처리 → 사용자 검수 → 시세표·연식 가격 계산 → Kakao Local API
```

- **AI는 '무엇인지'만 판단합니다.** Gemini가 물품의 라벨·위치·분류와 시세표 후보 중 제조사·모델명을 JSON으로 반환합니다. 사람·벽·천장은 제외합니다.
- **가격은 AI가 아닌 코드가 계산합니다.** 시세표에서 동일 모델 → 동일 제조사 → 동일 품목 순서로 제품을 찾습니다. 입력한 제조사·모델명이 시세표 제품과 일치하면 품목명과 관계없이 그 제품을 씁니다.

## 가격 산정 방식

```
y = 사용 개월 수 ÷ 12 (1개월 미만은 1개월)
y < 5 : 개당 가격 = 상한 − (상한 − 하한) × y ÷ 5
y ≥ 5 : 개당 가격 = 하한
연식 미입력 : (상한 + 하한) ÷ 2   (개업일을 넣으면 개업일 기준으로 계산)
```

| 기준 | 근거 |
|---|---|
| 거래사례(중고 시세)로 가치 평가 | 감정평가 실무기준(국토교통부 고시) 630 기계기구류 1.3 ② |
| 기구·비품 기준내용연수 5년 | 법인세법 시행령 제28조, 시행규칙 제15조 |
| 정액법(매년 균등 감가)·월할 계산 | 법인세법 시행령 제26조 제2항 제1호·제9항 |
| 내용연수 경과 후 감가 종료 | 법인세법 시행령 제26조 제6항·제7항 |

세법의 감가 방식을 팀 조사 중고 시세 범위에 적용한 **참고 시세**이며, 실제 거래가와 다를 수 있습니다.

## 데이터

- `data/reference_prices.csv` — 팀 조사 시세표 (25개 품목, 118개 제품: 신품가·중고 시세 하한·상한·상태 기준)
  - 원본: 팀 CSV `cafe_ultimate_verified_db.csv` (중고거래 불가·범위 미표기 2행 제외)
  - 중고 시세는 전문 커뮤니티 장터·B2B 중고주방·개인 직거래 시세를 종합한 팀 조사 추정값입니다.

## 파일

| 파일 | 역할 |
|---|---|
| `app.py` | 화면 (4단계 페이지) |
| `llm.py` | Gemini 탐지·후처리 (프롬프트: `prompts/item_filter_v4.md`) |
| `reference.py` | 시세표 조회·제조사/모델 매칭·연식 가격 계산 |
| `price.py` | 앱의 가격 조회 진입점 |
| `vendors.py` | Kakao Local API 판매처 검색 |
| `vision.py` | 이미지 변환·크기 조정 (HEIC 포함) |
| `box_selector/` | 사진 위 박스 그리기 컴포넌트 |
| `docs/개발과정_모델설정.md` | 개발·모델 선정 기록 |

## 로컬 실행

```bash
pip install -r requirements.txt
cp .env.example .env        # GEMINI_API_KEY, KAKAO_REST_KEY 입력
streamlit run app.py
python -m unittest discover -s tests -p "test_*.py"
```

API 키는 `.env`(로컬)와 Streamlit Secrets(배포)에만 두며, 저장소에는 올리지 않습니다.
