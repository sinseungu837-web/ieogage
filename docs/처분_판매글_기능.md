# 처분 선택·판매 준비 (2026-11-15)

## 사용자 흐름
사진 업로드·AI 분석 → 기존 물품 정보 수정 → 최종 분석 화면에서 처분 대상/방식 선택 → 선택한 물품의 참고 중고 가치 확인 → 개인 중고거래·전문업체 매각·양도/나눔 탭.

- 기존 4단계와 고정 설비·소모품 제외 규칙 유지. 가격 DB·알고리즘·탐지 코드는 변경하지 않음.
- 전체 선택/해제, 물품 묶음별 독립 선택. 해제해도 목록·시세·초안 보존.
- 합계는 선택된 물품의 참고 가치. 무료 나눔도 물품 가치는 표시하지만 현금 회수액으로 표현하지 않음. 실제 현금 회수 예상 합계는 산출하지 않음.
- 업체/나눔 목록 CSV, 전체 CSV의 처분 대상·방식 열, 판매글 TXT 다운로드.

## 구현 파일
- `disposal.py`: 객체 ID 묶음 키, 선택/분류, 합계, 입력 지문, 근거 문장 및 응답 검증.
- `disposal_view.py`: 체크박스/드롭다운, 결과 탭, 판매 조건·글 편집, 복사, 초안 적용.
- `llm.py`: `generate_sale_post` 추가. 기존 `_generate`, `_model`, API 키 구조 재사용.
- `prompts/sale_post_v1.md`: 판매글 전용 신규 프롬프트. 기존 탐지 프롬프트와 독립.
- `app.py`, `presentation.py`: 최종 화면 연결 및 합계 의미 명확화.
- `tests/test_disposal.py`: 상태·금액·근거 검증·Gemini 어댑터 모의 호출·Streamlit UI 테스트.

## 모델 및 정보 연동
기본 모델 `gemini-3.1-flash-lite`, 기존 `GEMINI_MODEL` 환경변수 및 대체 모델 정책 유지. 새 API/모델 도입 없음.

확정된 물품명·제조사·모델·수량·연식과 사용자 상태·특이사항·구성품·희망가격으로 코드가 사실 문장을 만듦. Gemini는 제목 후보와 문장 순서를 선택하며 반환한 인덱스를 검증한 뒤 제목/본문을 조립한다. 자유로운 광고 문구 생성은 제한되지만, 모델이 확인되지 않은 상태·보증·가격을 추가할 수 없다. 입력 안의 지시문도 명령이 아닌 데이터로 취급한다. 사용자가 입력한 내용의 진실성까지 검증하지는 않는다.

희망가격 기본값은 참고 단가×수량이며 전체 수량 합계로 명시한다. 시세가 없으면 빈 입력을 허용하고 가격 미정으로 작성한다. 참고 시세 자체는 LLM에 전달하지 않는다. 희망가격 수정은 참고 시세를 바꾸지 않는다.

세션의 `last['disposal']`에 초안·사용자 편집·조건을 보관한다. 위젯이 사라져도 값이 유지된다. 이름·제조사 수정은 ID가 같으면 상태 유지, 입력 지문 변경은 갱신 필요 표시. 묶음 분할·병합은 공통된 선택/방식을 이어받고 새 글을 작성한다. 충돌하는 선택은 기본 선택/미선택 방식으로 초기화한다. 이전 묶음 글은 `disposal_archive`에서 확인·복사 가능. 새 사진 분석은 기존 앱처럼 새 세션 분석 상태로 시작한다.

재생성은 후보 초안으로 표시하고 명시적 ‘새 초안 적용’만 기존 편집을 덮어쓴다. 후보 생성 후 정보가 바뀌면 적용 불가. 제목/본문 각각 Streamlit 코드 상자의 복사 버튼 제공. 브라우저 새로고침 후 영속 저장은 기존 session_state 범위 밖이다.
