# 카페 집기 데이터 추가·검수 결과 (2026-11-12)

## 최종 병합 범위

이 PR은 원문을 확인한 블렌더 매물 3건과 조사·검수 기록만 추가한다.
작업 중 팀원이 main에 반영한 #22, #24의 가격 계산·자동 수집·용량 구분·검수 기능을 그대로 유지한다.
처음 제안했던 엄격한 검증 스냅샷 게이트와 가격 표시 축소 변경은 이 PR에서 제거했다.
따라서 원본 대부분을 견적에서 제외하거나 price_table을 비우지 않는다.
사진 탐지·화면·가격 계산·크롤러 코드는 최신 main과 동일하다.

## 상세 조사와 제외 결과

소상공간 13개 상세와 카페다이렉트몰 3개 상세, 총 16건을 개별 확인했다.
기존 재확인 3건과 신규 후보 13건이다. 검증 완료 5건(기존 2+신규 3), 확인 대기 7건,
제외 4건이다. URL 중복 제거로 제외한 행은 0건이다.
확인 대기/제외 후보를 새 운영 행으로 넣지 않았다. 이 조사 판정이 기존 96건 전체의 검수 결과는 아니다.

- 판매 완료 여부와 실제 체결액을 구분했다. 가격이 표시돼도 현재 매물이 아닐 수 있다.
- 정상 작동 설명이 부족한 제빙기·오븐은 확인 대기다.
- JSON-LD가 UsedCondition이어도 본문에 새제품이라고 명시한 1건은 제외했다.
- 전문 판매처의 유사 페이지 3건은 구매·품절 버튼이 모두 숨김이며 중복 재고 가능성도 있어 확인 대기다.
- 판매자 연락처·이미지·본문 전체를 배포하지 않는다. 게시일을 확정하지 못한 경우 비웠다.

## 출처 접근과 수집 한계

소상공간은 상세 HTTP 200의 Product/Offer 가격·KRW·중고·판매 상태를 본문과 대조했다.
robots는 공개 상품 경로를 허용하지만 일부 학습 봇을 금지하고 /terms는 404다.
자동 반복 수집 허가로 해석하지 않고 사용자 요청 범위의 소수 원문 검토만 수행했다.
카페다이렉트몰·커피과학의 robots/약관은 200이었으나 영리 이용 제한 등이 있어 자동 수집 출처로 새로 등록하지 않았다.
커피과학은 중고 카테고리까지만 확인했고 개별 검증 데이터 확보는 완료하지 못했다.
헬로마켓 robots는 200, 약관은 500이었다. 신규 대량 수집을 실행하지 않았다.
온비드 최소 HTTPS 요청은 503 upstream_connection_timeout으로 실패했다. 인증 성공이나 정상 0건으로 해석하지 않았다.
키/요청 URL을 기록하지 않았고, 접근 제한 우회나 기관 연락을 하지 않았다.

## 검증과 다음 작업

최신 main의 가격 로직으로 요약 CSV를 재생성했다. 가격 성격을 분리하고 원본 96행과 신규 3행의 URL 중복이 없음을 확인했다.
계산 로직 자체를 바꾸지 않았으므로 블렌더 2건을 3건으로 부풀리거나 다른 모델로 보충하지 않는다.
현재 판매 중인 동일 모델·동일 구성의 정상 매물 1건 이상을 더 확보하는 것이 우선이다.
추천 5건까지 충분한 표본을 모으는 작업과 냉동고·쇼케이스·정수/온수기·오븐 등 확대는 미완료다.
초기 데이터 확보 목표에 비해 실수집이 3건에 그친 점을 명시한다. 검수 기준 강화만으로 DB 확장이 완료된 것은 아니다.
업데이트는 팀원이 추가한 coverage, refresh, review-queue, apply-review 기능과 기존 수동 검증 경로를 사용한다.
엄격한 검증 정책 도입은 충분한 데이터 확보와 가격 표시 영향 검토 후 별도 변경으로 다룬다.
