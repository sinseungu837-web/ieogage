## 4. 전문 판매처와 수집 한계

전문 업체를 먼저 조사했지만 이번 신규 승인 데이터는 일반 거래 플랫폼의 수동 검증 2건이다.
수집이 허용된 전문 업체에서 비교 가능한 3건을 확보했다는 목표는 달성하지 못했다.

- 로얄살롱은 robots/약관부터 403이므로 우회하거나 반복 수집하지 않았다.
- CBM은 robots 공개 경로 허용, /terms 404. 소수 공개 상세만 개별 검토하고 자동 수집 출처로 등록하지 않았다.
  IMK-3051은 판매 완료이고 현재 가격도 없어 제외. 아이스트로 현재 상품 4건은 모델이나 정상작동 설명이 부족해 대기.
  ‘35kg’라는 공통 용량만으로 전부 ICI-043 모델이라고 채우지 않았다.
- 소상공간 신규 IMK-3051 2건은 상태 근거 부족 또는 제목51kg/본문30kg 충돌로 대기.
- 중고나라 5개 후보는 현재 정상 중고 2건 승인, 판매 완료 2건·404 1건 제외.
  robots는 공개 상품 경로 허용이다. /terms 응답 200은 전체 이용 허가를 입증하지 않으므로 반복 수집기를 등록하지 않았다.
- 헬로마켓 약관은 500. 기존 매물의 한정된 원문 검토만 수행했다.

`policy_checks.json`, `new_candidates.csv`, `rendered_pending.json`에 접근/판정 범위를 기록했다.
검색 결과 가격이나 신품가 감가 계산으로 이번 신규 데이터 값을 채운 건은 없다.

## 5. 서비스 연동과 검증

이 데이터 PR은 CSV·검수/조사 문서만 수정한다. 최신 main의 수집·탐지·화면 코드를 보존한다.
기존 16열 스키마와 가격 성격(sold_posted/asking/auction)을 유지한다.
`manual_reviews.csv`에 신규 2건의 검증 메모를 추가하고, 기존 NC-313의 충돌 표기도 검수 스냅샷과 맞췄다.
팀원의 coverage/review-queue 생성기를 사용해 현황 파일을 갱신했고, 사람이 작성한 확인결과가 없음을 확인 후 재생성했다.

별도 PR #26은 입력 사양이 비어 있어도 서로 다른 사양군을 표본 3건으로 합치지 않도록 DB 집계를 수정했다.
사양 미확인군은 명시하고 신뢰도를 낮춘다. DB 우선 → 헬로마켓 실시간 검색 등 조회 순서는 유지한다.
전역 검증 게이트·미검증 데이터 일괄 삭제·가격 전체 공란화 변경은 하지 않았다.

견적 요약 10그룹은 기존 코드의 통계 생성 기준을 충족한다는 뜻이며, 원문·작동·사양 검증 완료 그룹 10개라는 뜻이 아니다.
모델이 있는 3건 이상 그룹은 여전히 2개다. 이번에 새로 3건을 충족한 비교 그룹은 0개다.
특히 공매의 개별 원문 미확인과 기존 일반 품목 데이터의 용도 혼재는 남아 있다.

원본 보존, 허용된 15개 셀만 변경, URL 중복 없음, 신규 상세 근거, 현재/판매 완료 구분 및 계산 결과를 확인했다.
테스트 결과는 PR과 최종 보고에 기재한다. 실제 AI 탐지 정확도를 이 작업의 데이터 검증으로 주장하지 않는다.
